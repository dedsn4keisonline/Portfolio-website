NAME

netsec-lab

a safe space for hacking

DESCRIPTION

As a cybersecurity enthusiast, I wanted a safe environment to test firewalls, intrusion detection systems (IDS), and penetration testing tools. So I built a network security lab.

It's a simulated environment where I can experiment without risking real-world systems. Here's how I did it.

COMPONENTS

Firewall
pfSense simulates and tests firewall rules.
IDS
Snort monitors network traffic for suspicious activity.
Pentesting
Kali Linux and tools like Metasploit for ethical hacking.
Virtualization
VMware ESXi creates isolated virtual networks.

SETUP

Virtual environment

I started by building the virtual environment on VMware ESXi:

  1. Install VMware ESXi on a dedicated server.
  2. Create virtual machines (VMs) for the network components: firewalls, IDS, and targets.
  3. Configure virtual networks to isolate traffic for testing.

pfSense firewall

Next, I set up pfSense as the lab's firewall:

  1. Install pfSense on a VM and configure it as the gateway for the virtual network.
  2. Create firewall rules that simulate different scenarios, such as blocking specific traffic.
  3. Test the rules to make sure they work as expected.

Snort IDS

To monitor network traffic, I deployed Snort as an intrusion detection system:

  1. Install Snort on a VM and configure it to monitor traffic on the virtual network.
  2. Create custom rules that detect specific attacks, such as port scans and SQL injection.
  3. Test Snort by simulating attacks and verifying the alerts.

Penetration testing

Finally, I used Kali Linux to test the lab's security:

  1. Install Kali Linux on a VM and set it up with tools like Metasploit, Nmap, and Wireshark.
  2. Simulate attacks on the virtual network to test the firewall and IDS.
  3. Analyze the results and improve the security setup.
